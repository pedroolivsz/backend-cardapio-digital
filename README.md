## Cadarpio Digital - API

Essa API tem como objetivo conectar a minha aplicação com o seu banco de dados, atuando na criação, 
manipulação e exclusão de dados no banco de dados PostgreSQL. Ela atua com alta eficiência com o auxílio 
de WebSockets.

## Tecnologias utilizadas

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Web MVC
- Spring DevTools
- Spring Validation
- Spring WebSocket
- Lombok
- PostgreSQL
- Maven

## Funcionalidades

- Cadastro de produtos
- Consulta de produtos
- Atualização de produtos
- Exclusão de produtos

## Pré-requisitos

- Java 21
- Maven
- PostgreSQL

## Como executar o projeto

1. Clone o repositório.
2. Configure as variáveis de ambiente.
3. Execute a aplicação.

```bash
./mvnw spring-boot:run
```
